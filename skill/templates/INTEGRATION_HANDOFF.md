# 跨模块接口交接模板

本表只在有实际证据时填写，不表示接口已经实现。适用于HLS↔主机、DPU↔后处理、Host↔OFDM、ROS1↔ROS2及模型↔控制器。

用法：复制到双方认可的新记录，逐字段附源码/规格位置，先填未知再补证据；失效：版本、单位或完成/释放条件未明确时不能签为接口已对齐。经验来源：[缓冲/状态源码](/home/amd/kv260-ofdm-reproduction/src/ps/kv260_B3136/runtime/hardware.py)与[跨层缺口](/home/amd/kv260-ofdm-reproduction/report/KNOWN_GAPS.md)。已验证效果限定为依据这些观察提取了可审查字段、引用可检查；未证明新队伍集成成功率。

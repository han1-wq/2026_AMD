# 测试数据和参考结果

存放已有测试向量、模型权重、参考输出和设备相关标定资料。

- `ofdm/captures/`：原OFDM数据/图像捕获材料。
- `models/`：B3136和历史视觉分支的编译模型，保留配套说明/配置。
- `lerobot/workspace/`：缩小ACT传输检查、采集/标定记录和原工作数据；依赖下载cache排除。
- `reference/INDEX.csv`：mem/coe/hex、地图、fixture、权重等参考文件索引。

历史标定文件只能用于对应实体设备，不得作为其他设备的通用配置。缩小随机ACT权重不是训练完成的抓取模型。性能占位数值不作为实测数据新增；原报告如含性能表仍须按原范围审查。图像、设备身份和地图等公开发布前需人工隐私审查。
